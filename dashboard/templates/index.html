1. Ingestion Layer

High-frequency Kafka stream (Confluent Cloud) + Auto Loader JSON watchlist ingestion with schema inference and evolution.

2. Medallion Processing

Bronze raw tables enriched to Silver with Databricks Declarative Pipeline Expectations (@dlt.expect, @dlt.expect_or_drop), stream-stream joins with 5-minute watermarks to bound memory state.

Gold materialized views feeding sub-second Lakeview dashboards and automated SMTP email notification triggers for high-risk flags.
